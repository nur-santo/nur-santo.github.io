Dua aplikasi terintegrasi untuk manajemen kehadiran karyawan berbasis web dan mobile.

01 / Web Admin

Sistem Manajemen Absensi

Panel Admin berbasis Web menggunakan Laravel
GitHub

Menampilkan ringkasan data kehadiran, statistik, serta grafik tren harian dan distribusi status.

Menampilkan semua karyawan yang terdaftar beserta form tambah pengguna.

02 / Mobile App

Aplikasi Absensi Karyawan

Aplikasi mobile Flutter dengan Face Recognition dan REST API
GitHub

Tampilan Utama

Antarmuka utama aplikasi untuk karyawan melakukan absensi dan melihat riwayat.

Perizinan

Pengajuan izin, sakit, atau cuti dengan input tanggal, keterangan, dan upload bukti opsional.

Riwayat Kehadiran dan Perizinan

List riwayat absensi harian beserta status pengajuan izin.

Alur Sistem

  1. User login dengan akun terdaftar
  2. User melakukan absensi via face capture atau foto
  3. Data dikirim ke backend API
  4. Backend validasi wajah via Face Recognition API
  5. Data absensi disimpan ke database
  6. User dapat melihat riwayat kehadiran

Keunggulan Sistem

  • Absensi lebih akurat dengan face recognition
  • Mendukung mode WFO dan WFH
  • Monitoring real-time oleh admin
  • Terintegrasi sepenuhnya dengan REST API

Teknologi

Flutter REST API Camera Integration Face Recognition API
